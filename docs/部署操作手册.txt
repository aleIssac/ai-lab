================================================================
  AI 教学实训平台 —— 部署操作手册
================================================================
日期：2026-10-20
适用：Windows 10 / 11 64 位 + Docker Desktop
说明：整份手册按顺序做完即可，不需要联网（除安装 Docker Desktop 本身）

----------------------------------------------------------------
  这个包里有什么
----------------------------------------------------------------
  images\ai-lab-1.0.tar      1.6 GB   编辑器 + Python/PyTorch/Spark
  images\ollama-latest.tar   3.6 GB   Ollama 模型服务
  project\                   2.3 GB   整个项目
      project\ollama-models\    941 MB  两个模型（对话 + 补全）
      project\docker\extensions 364 MB  11 个编辑器扩展（含 Tab 补全）
      project\apps\             876 MB  Transformer 可视化、ConvNetJS
  install.bat                         一键安装（双击它）
  部署操作手册.txt                     本文件

  合计约 7.4 GB


----------------------------------------------------------------
  一、目标电脑需要什么
----------------------------------------------------------------
必须满足：
  1) Windows 10 2004（build 19041）及以上，或 Windows 11 64 位
  2) BIOS 里已开启虚拟化（Intel VT-x / AMD-V）
  3) Docker Desktop（WSL2 后端）
  4) C 盘至少 15 GB 空闲（镜像解压后约占 11 GB）
  5) 以下端口空闲：3000 5001 8000 8080 8501 8502 11434

不需要安装：
  Python、Node、VS Code、Ollama、任何模型文件、任何浏览器插件

注意：
  Windows Server（2016/2019/2022）不支持 Docker Desktop，
  需要改成 WSL2 里装 Docker Engine，步骤不同，请先确认目标机系统版本。


----------------------------------------------------------------
  二、操作顺序（照做即可）
----------------------------------------------------------------

第 1 步  拷贝部署包（约 10 分钟，取决于 U 盘速度）

  放在哪里（这条很重要）：
  - 必须是本地物理硬盘：D:\ai-lab 或 E:\ai-lab 都可以
  - 不要放网络共享盘 / NAS / 映射盘 —— Docker 挂载会失败或读写异常
  - 不要放 U 盘、移动硬盘里直接运行（拔掉就崩）
  - 不要放 C:\Program Files、C:\Windows 等受保护目录（写不进去）
  - 不要放 OneDrive 等同步目录（同步线程会和容器抢文件）
  - 路径可以带中文，但建议不含空格和 & ( ) # 这些字符
  - 目录层级不要过深（Windows 路径上限 260 字符，扩展目录本来就深）

  推荐直接用：  D:\ai-lab\

  成功标志：文件夹里能直接看到 install.bat

  注意：装完之后这个文件夹就是“运行目录”，不能删、不能改名、不能移动。
        容器把里面的 project 目录挂载成了工作区，删掉服务立刻挂。
        以后要换盘：先跑 project\stop.bat，再整体移动，最后在新位置跑 start.bat。

第 2 步  安装 Docker Desktop（约 15 分钟，含一次重启）
  - 如果目标机没有外网，提前把 Docker Desktop 安装包（约 500 MB）
    一起拷过去
  - 双击安装，安装类型选 WSL 2 backend（不是 Hyper-V）
  - 安装完成后必须重启电脑
  - 重启后启动 Docker Desktop，接受协议，等待左下角显示
    “Engine running”（鲸鱼图标不再转圈）

第 3 步  验证 Docker（1 分钟）
  打开 cmd，依次执行：
      docker --version
      docker compose version
      docker info
  三条都能正常输出（不报 Cannot connect）才继续

第 4 步  安装平台（约 5 分钟）
  双击  部署包\install.bat
  它会自动做三件事：
      1. 加载两个镜像
      2. 检查模型库是否完整
      3. 调用 project\start.bat 启动全部服务
  最后屏幕会打印一串地址，看到下面这两行就是成功了：
      Portal        http://localhost:3000
      code-server   http://localhost:8080

第 5 步  打开门户
  浏览器访问 http://localhost:3000
  点页面上的“检测服务状态”，六个卡片都应显示“在线”

第 6 步  逐项验证（建议按这个顺序）
  ① 浏览器内开发
     打开 http://localhost:8080，密码见 .env 的 CODE_SERVER_PASSWORD
     打开 test.py，点右上角运行按钮，能输出 Python/Torch 版本
  ② 智能补全与自动注释
     补全：在 test.py 末尾新起一行，输入   def avg(   停一秒
     光标后应出现灰色斜体文字（如 x, y): 和 return (x + y) / 2）
     按 Tab 键落成真代码
     注意：容器刚启动时模型是冷的，第一次可能等 6 秒，等半分钟再测
     注释：选中一段代码后按 Ctrl+Alt+C，约 5 秒自动加中文文档字符串和行内注释；
           不选中直接按 Ctrl+Alt+Shift+C，则给整个文件所有函数批量加
  ③ 报错诊断
     在编辑器里故意写错一行（如 print(1/0)），运行得到 traceback
     在终端里选中 traceback 按 Ctrl+C 复制，回到编辑器按 Ctrl+Alt+K
     约 3 秒后右侧新开「报错诊断」标签页：类型 / 定位 / 修复代码 / 优化建议
  ④ 三个专项
     预测页面  http://localhost:8501
     RAG 问答  http://localhost:8502
     MLflow    http://localhost:5001
     Notebook  在 8080 里新建 .ipynb
  ⑤⑥⑦ 可视化
     门户里点“开始实验”“打开可视化”，或直接访问：
       神经网络   http://localhost:3000/nn-playground/
       Transformer http://localhost:3000/transformer-explainer/
       经典算法   http://localhost:3000/convnetjs/demo/classify2d.html

第 7 步  日常启停
  启动：双击 project\start.bat   （每次开机后都要执行一次）
  停止：双击 project\stop.bat    （停止时把容器一起删掉，数据不丢）


----------------------------------------------------------------
  三、注意事项（都是实际踩过的坑）
----------------------------------------------------------------

1. 必须放本地硬盘
   Docker 不支持把项目放在网络共享盘上挂载，会启动失败或文件读写异常。

2. 不要用 Windows Server
   Docker Desktop 只支持 Windows 10/11 客户端系统。

3. C 盘空间
   Docker 的数据默认在 C:\Users\<用户名>\AppData\Local\Docker。
   空间不够时 docker load 会报 no space left on device。
   处理：Docker Desktop → Settings → Resources → Advanced
        → Disk image location 改到 D 盘 → Apply & restart

4. 端口冲突
   安装前先检查，任何一个被占用都会导致对应服务起不来：
       netstat -ano | findstr ":3000 :8080 :8501 :8502 :5001 :8000 :11434"

5. 第一次补全慢是正常的
   模型要从磁盘加载进内存（约 6 秒），之后就是 100 毫秒级。
   补全扩展在启动时会自动预热，失败会每 5 秒重试，最多 20 次。

6. 不要用记事本改 start.bat / stop.bat / install.bat
   这三个文件必须是 ANSI(ASCII) 编码 + Windows 换行。
   用记事本保存成 UTF-8 或改成中文注释，会让脚本被 cmd 切碎执行，
   现象是一堆“'docker' 不是内部或外部命令”加乱码片段。

7. 容器重启后服务不会自动恢复
   MLflow、两个 Streamlit、预测 API、补全代理、门户都跑在容器里，
   每次开机或重启 Docker 之后，必须重新双击 project\start.bat。

8. 打不开页面先清缓存
   Ctrl + F5 强制刷新；code-server 换版本后尤其需要。

9. 装了安全软件 / 防火墙
   部分安全软件会拦截 Docker 的端口映射，表现为容器在跑但端口访问不通。
   临时关掉试试，确认后再加白名单。

10. 验收当天不要做这些事
    - 不要 docker compose down -v 之后不重启（会清掉容器）
    - 不要改 docker-compose.yml 里的镜像名
    - 不要手动 kill 容器内进程，用 stop.bat 统一停


----------------------------------------------------------------
  四、出问题怎么查
----------------------------------------------------------------
现象                          处理
---------------------------   --------------------------------------
install.bat 一闪而过          在 cmd 里手动执行 install.bat，能看到报错
docker load 报空间不足        见“注意事项 3”，改 Docker 磁盘位置
打不开 3000                   docker exec -d ai-lab bash -c "cd
                              /home/coder/project && /opt/venv/bin/
                              python tools/serve_portal.py 3000 >
                              /tmp/portal.log 2>&1"
                              然后 docker exec ai-lab cat /tmp/portal.log
8501 / 8502 打不开            docker exec ai-lab tail -30 /tmp/st.log
                              （RAG 看 /tmp/rag.log）
MLflow 页面空白               docker exec ai-lab tail -20 /tmp/mlflow.log
补全不出灰色文字              docker exec ollama ollama list
                              （应看到 qwen-coder-fim 和 qwen2.5-coder）
                              curl http://localhost:11435
                              （应返回 {"proxy":"ok","upstream":200}）
编辑器打不开/白屏             docker exec ai-lab tail -20 /tmp/proxy.log
                              浏览器 Ctrl+F5；确认 8080 没被占用
所有服务都 200 但门户卡片“离线”  门户的检测走 localhost，
                              确认是在目标机本机打开的浏览器


----------------------------------------------------------------
  五、常用命令
----------------------------------------------------------------
查看容器状态          docker ps
查看可用模型          docker exec ollama ollama list
进入容器              docker exec -it ai-lab bash
看某个服务日志        docker exec ai-lab tail -50 /tmp/portal.log
重启全部服务          双击 project\start.bat
停止并删除容器        双击 project\stop.bat
彻底重装（镜像保留）  双击 project\stop.bat，再双击 project\start.bat
卸载镜像              docker rmi ai-lab:1.0 ollama/ollama:latest
