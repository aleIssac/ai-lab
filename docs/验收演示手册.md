# 验收演示手册

> 七个验收点，全部在一台机器上跑通。本文是验收当天的操作说明。

---

## 一、端口总览

| 端口 | 服务 | 对应需求 |
|---|---|---|
| **3000** | 演示门户（含 playground、Transformer 可视化） | ⑤⑥ |
| **8080** | code-server（浏览器 IDE） | ①②③ |
| **8000** | 预测 API（FastAPI） | ④ |

## 二、启动

### 本机验证版（Windows 原生，已跑通）

```bash
# 1. 演示门户（⑤⑥ 都在这个端口下）
python tools\serve_portal.py 3000

# 2. 预测 API
D:\Environment\Server\venv\Scripts\python.exe -m uvicorn src.serve:app --host 0.0.0.0 --port 8000

# 3. MLflow
D:\Environment\Server\venv\Scripts\python.exe -m mlflow ui --backend-store-uri sqlite:///mlflow.db --host 0.0.0.0 --port 5001

# 4. Streamlit
D:\Environment\Server\venv\Scripts\python.exe -m streamlit run apps/streamlit_app.py --server.address 0.0.0.0 --server.port 8501
```

浏览器打开 **http://localhost:3000**。

### 目标机版（Docker，一键）

```powershell
# 1. 填 API Key
notepad config\config.yaml

# 2. 启动
.\start.bat

# 3. 打开 http://localhost:8080（密码见 .env 的 CODE_SERVER_PASSWORD）
```

## 三、演示脚本（8 分钟）

### 0:00 开场（30 秒）

打开 `http://localhost:3000`，点击「检测服务状态」，各卡片亮起绿灯。

> 话术："七个功能模块，统一入口。左边三个是开发环境，中间是实训流程，右边是可视化实验。"

---

### 需求①②③ 开发环境 + AI 辅助（3 分钟）

打开 `http://localhost:8080`，新建 `demo.py`：

**① 编码与调试**
- 输入一段训练 MNIST 的代码 → 按 `F5` → 在 `model.fit` 前下断点
- 展示：变量面板（tensor 形状）、调用栈

> 关键点：能下断点看张量形状，这是 Jupyter 做不到的。

**② 智能补全**
- 输入 `def train_epoch(` 后停住 → 按 `Tab` 接受补全
- 选中整个函数 → 按 `Ctrl+Alt+C` → 约 5 秒后函数上方出现中文文档字符串、关键语句上方出现 `#` 注释
- 想给整个文件所有函数一次性加：不选中，直接按 `Ctrl+Alt+Shift+C`

**③ 报错诊断**
- 故意写 `x = torch.randn(3, 4); y = torch.randn(3, 5); z = x @ y`
- 运行报错 → 终端里选中 traceback 复制 → 回到编辑器按 `Ctrl+Alt+K`
- 约 3 秒后右侧新开「报错诊断」标签页，四段式输出：类型 / 定位 / 修复代码 / 优化建议
- （也可以直接在编辑器里选中 traceback 再按 `Ctrl+Alt+K`，不必复制）
- 模型会指出"矩阵维度不匹配，(3,4) @ (3,5) 无法相乘"

### 需求④ 端到端实训（3 分钟）

**第一步：Notebook**

打开 `http://localhost:8080` 里的 `courses/01-ai-app/01-数据清洗.ipynb`，逐格运行：

| Cell | 演示点 |
|---|---|
| `df.info()` | 数值列因为 `N/A` 变成了 object |
| `pd.to_numeric(errors='coerce')` | 类型转换后 NaN 暴露出来 |
| 异常值处理 | 年龄 999、月费负数被置为缺失 |
| 去重 | 删除 45 行重复记录 |

> 话术："1545 行脏数据，清洗后剩 1500 行，四类问题全部处理。"

**第二步：训练与实验记录**

终端执行 `python src/train.py`，然后打开 `http://localhost:5001`（界面已汉化，术语与数据保持英文原样）：

- 展示三条 run 的指标对比表
- 点进 RandomForest 那条，看混淆矩阵图

> 话术："三组超参实验，F1 从 0.657 提升到 0.712，AUC 0.937。每次尝试都有记录。"

**第三步：部署发布**

打开 `http://localhost:8000/docs`，在 `/predict` 上点 "Try it out"，填一个高风险客户：

```json
{"age":29,"tenure_months":3,"monthly_charge":130,"total_charge":390,
 "contract_type":"按月付费","payment_method":"电子支票","support_calls":9,"is_active":0}
```

返回 `{"churn":1,"probability":0.9199,"risk_level":"高"}`。

> 话术："模型已经不是文件，是一个在线服务，任何系统都能调。"

**第四步：可视化页面**

打开 `http://localhost:8501`，拖动滑块，概率实时变化。

**第五步：大数据专项（Spark）**

打开 `courses/02-bigdata/01-Spark数据清洗.ipynb`，逐格运行：

- 讲到 `filter` / `withColumn` 时说"这些**还没真正计算**，只是建了执行计划"，再跑 `count()` 触发
- 跑完打开 `http://localhost:4040`，指着 **DAG 图、Stage 划分、Shuffle 读写量**说："这是分布式作业的体检报告，pandas 是没有的"

再打开 `02-SparkML训练.ipynb`，跑 Pipeline，最后打印两个模型的 AUC。

**第六步：大模型专项（RAG）**

打开 `http://localhost:8502`，侧栏默认已指向本地模型（Key 填 `ollama`、Base URL `http://ollama:11434/v1`、模型 `qwen2.5-coder:1.5b`），点示例问题「矩阵维度不匹配怎么排查」，约 7 秒出答案：

- 右侧展开引用卡片，看命中的是 `PyTorch常见错误.md · 张量形状不匹配`，相似度 0.195
- 话术："答案是**从这三份文档里检索出来的**，不是模型凭记忆编的，每条都标了出处"
- 想讲 RAG 的两段结构：把 Key 清空再问一次，页面会展示拼好的完整 prompt（检索结果 + 问题 + 约束）
- 想用云端模型：Base URL 改 `https://api.deepseek.com/v1`、模型 `deepseek-chat`、填自己的 Key

> 这一步的价值在于**可验证性**：模型说的每句话都能追溯到某个文件。

### 需求⑤ 神经网络超参实验（1 分钟）

`http://localhost:3000/nn-playground/`

- 选「spiral」数据集 → 加隐藏层到 4 层 → 每层 6 个神经元 → 激活函数切 ReLU
- 点播放，观察决策边界和右侧 loss 曲线同步下降
- 手动改学习率 0.03 → 0.003，对比收敛速度差异

> 话术："层数、神经元数、激活函数、学习率全部在线可调，训练过程实时可见。"

### 需求⑦ 经典算法可视化（1.5 分钟）

门户第 7 张卡片，六个实验全部在浏览器内实时训练：

| 实验 | 路径 | 演示点 |
|---|---|---|
| **MNIST CNN** | `/convnetjs/demo/mnist.html` | 卷积网络识别手写数字，默认参数几分钟内可达 99% |
| **CIFAR-10 CNN** | `/convnetjs/demo/cifar10.html` | 同一套网络结构处理彩色图，明显更难 |
| **自编码器** | `/convnetjs/demo/autoencoder.html` | 用 2 个神经元的瓶颈压缩再重建 |
| **DQN 强化学习** | `/convnetjs/demo/rldemo.html` | 9 只眼睛、5 个转向角度，学习避开毒物 |
| **2D 分类** | `/convnetjs/demo/classify2d.html` | 鼠标加点，实时看决策边界怎么变 |
| **1D 回归** | `/convnetjs/demo/regression.html` | 曲线拟合，直观理解回归 |

**演示话术**：

- 打开 MNIST，指着右侧 loss 曲线说"这条线是刚刚这几秒钟算出来的"
- 点 `pause` → 把 `Batch size` 从 20 改成 5 → `change` → 恢复，展示**超参对收敛的影响**
- 切到 `classify2d`，用鼠标在画布上点几个点，立刻看到网络重新画边界——这是"交互式"最直观的一幕

**关键事实**：六个实验全部在浏览器里用 JS 计算，**没有后端、没有 GPU、没有网络请求**。断网也能演示。

**数据说明**：MNIST（21 张拼图，12 MB）和 CIFAR-10（51 张拼图，138 MB）已按 ConvNetJS 的内部格式重新生成并本地化，直接可用。

## 四、应急方案

| 情况 | 处理 |
|---|---|
| **断网** | ①②③ 的 AI 功能不可用，其余照常。IDE 本身、代码运行、④⑤⑥⑦ 全部离线可用 |
| **API Key 失效** | 换 `config\config.yaml` 里的 Key 后重启 code-server |
| **MLflow 页面打不开** | Windows 5000 端口常被占用，务必用 5001 |
| **notebook 结果对不上** | 执行 `Restart Kernel & Run All`，不要依赖之前的运行状态 |
| **端口冲突** | `netstat -ano | findstr :3000` 查占用进程 |
