ConvNetJS · MNIST 手写数字演示

说明

本演示在浏览器内以纯 JavaScript 训练一个卷积神经网络，数据集为 MNIST 手写数字。该数据集难度较低，通常几分钟即可达到约 99% 的准确率。数据由 python 脚本 从 原始文件 解析为图片批次，便于通过 img 标签载入页面。

网络输入 28×28 的 MNIST 图像，训练前随机裁剪 24×24 窗口（数据增强，提升泛化能力）；预测时采样 4 个随机裁剪窗口，对其概率取平均作为最终结果。在常规 Ubuntu + Chrome 环境下，前向与反向传播单次各约 5ms。

本演示默认使用 Adadelta——一种逐参数自适应步长方法，无需随训练过程手动调整学习率与动量；同时保留相应输入框，可切换至 SGD+Momentum 训练器试验。
